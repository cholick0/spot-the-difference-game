A "Spot the Difference" browser game with three original procedurally drawn
scenes — Lantern Harbour at dusk, Night Market, and Sunny Garden — 7
differences each, 21 total. Side-by-side canvas play: click to mark
differences, with scoring, combo and time bonuses, hints (3 per round),
shrinking per-round timers, and synthesized WebAudio sounds. Vanilla
JavaScript and canvas only — no files, no network.
